## Tags

*Combat*{ .chip .chip-warning }
:	Skill has active or passive benefit during combat

*Craft*{ .chip .chip-note }
:	Skill plays a role in directly crafting items or adds a benefit to items that are crafted

*Gather*{ .chip .chip-quote }
:	Skill uses specific tools to gather raw resources from the environment

*Gold*{ .chip .chip-question }
:	Skill is known to produce a notable amount of gold

*Loot*{ .chip .chip-success }
:	Skill is known to produce a notable amount of loot

*Magic*{ .chip .chip-example }
:	Skill is known to be used for casting or enhancing spells

*Pet*{ .chip .chip-bug }
:	Skill plays a role in creating, controlling, or maintaining pets
