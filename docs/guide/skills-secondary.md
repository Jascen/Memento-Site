# Secondary Skills
In an effort to make resource *Gathering* and *Crafting* skills more accessible, Memento has created *Secondary* Skills.

The following skills <u>will not be counted</u> against your character's total skill cap:

## Alchemy
*Combat*{ .chip .chip-warning }
*Craft*{ .chip .chip-note }
*Pet*{ .chip .chip-bug }

- Craft powerful potions to boost your gameplay
- Brew magical Elixirs to enhance skills
- Summon slimy companions to aid you in combat
- Soak the battlefield with dangerous liquids
- Tools
	- Mortar and pestle
	- Alchemy tub (to clean bottles)
	- Potion keg (to store up to 100 of the same potion)
- Related
	- [Carpentry](#carpentry) - craft an alchemy tub and potion keg
	- [Tinkering](#tinkering) - craft your own tools

## Blacksmithing
*Craft*{ .chip .chip-note }
*Gold*{ .chip .chip-question }

- Craft metal armor and weapons when next to an *anvil* and *forge*
- Layer tough scales to create magical armors
- Refine rare metals into powerful armor and weapons
- Sell crafted goods to vendors
- Tools
	- Scaling tools
	- Smith's hammer
- Related
	- [Mining](#mining) - gather ore and smelt into ingots for crafting
	- [Tinkering](#tinkering) - craft your own tools

## Forensics
!!! info "Old name: Forensic Evaluation"

*Craft*{ .chip .chip-note }
*Gather*{ .chip .chip-quote }
*Loot*{ .chip .chip-success }
*Magic*{ .chip .chip-example }
*Pet*{ .chip .chip-bug }

- Determine who has interacted with a corpse or container by using this skill on it
- Stitch bones into impenetrable armors
- Dig up graves to uncover treasure and bones to craft with, but watch out for the law!
- Increase yield of raw resources when carving creatures
- Assemble the creature of a well known scientist
- Tools
	- Undertaker tools (can only purchase at this time)
	- Grave shovel
	- Skinning knife
	- Witch's cauldron
- Related
	- [Blacksmithing](#blacksmithing) - generate more gem blocks from elementals
	- [Necromancy](skills-primary.md#necromancy) - brew magical conctions with a witch's cauldron
	- [Tailoring](#tailoring) - generate more skins from creatures
	- [Tinkering](#tinkering) - craft your own tools

## Lumberjacking
*Combat*{ .chip .chip-warning }
*Gather*{ .chip .chip-quote }

!!! tip "Some woods can only be mined in certain lands and regions"

- Use an axe and target trees to harvest logs
- Process the *logs* into *boards* by using them on a *sawmill*
- Tools
	- Hatchet (or any axe)
- Related
	- [Swordsmanship](skills-primary.md#swordsmanship) - provide damage bonus when using axes
	- [Tinkering](#tinkering) - craft your own tools

## Mining
*Combat*{ .chip .chip-warning }
*Gather*{ .chip .chip-quote }

!!! tip "Some ores can only be mined in certain lands and regions"

- Use a tool on cave floors, mountainsides, and glistening ore veins to gather ore
- Refine *ore* and precious metals into craftable ingots by using it on a *forge*
- Dig up precious gems
- Tools
	- Pickaxe
	- Shovel
- Related
	- [Bludgeoning](skills-primary.md#bludgeoning) - provide damage bonus
	- [Tinkering](#tinkering) - craft your own tools

## Tailoring
*Combat*{ .chip .chip-warning }
*Craft*{ .chip .chip-note }
*Gold*{ .chip .chip-question }

!!! tip "It is rare to find cloth in the wild. Try buying it from vendors instead."

- Craft different types of leather armor
- Sew using different fabrics to create clothing with magical attributes
- Stitch rare animal skins into powerful armor and weapons
- Sell crafted goods to vendors
- Tools
	- Sewing kit
	- Tanning tools
- Related
	- [Fist Fighting](skills-primary.md#fist-fighting) - provide damage bonus to pugilist gloves
	- [Marksmanship](skills-primary.md#marksmanship) - provide damage bonus to throwing gloves
	- [Tinkering](#tinkering) - craft your own tools

## Tinkering
*Combat*{ .chip .chip-warning }
*Craft*{ .chip .chip-note }
*Gold*{ .chip .chip-question }
*Pet*{ .chip .chip-bug }

- Unique ability to create suppliment crafting tools for other skills
- Craft a golem to fight for you
- Set traps to kill or maim creatures
- Sell crafted goods to vendors
- Tools
	- Trapping tools
	- Tinker tools
- Related
	- [Alchemy](#alchemy) - attach potions to trapping tools
	- [Remove Trap](skills-primary.md#remove-trap) - increase the damage of your traps
	- [Mining](#mining) - gather ore and smelt into ingots for crafting
